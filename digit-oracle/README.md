# Digit Oracle

Handwritten digit recognition with emlearn, on the Adafruit CLUE and the
Adafruit PyBadge. A small neural network (one hidden layer of 64 neurons,
51 KiB of flash) trained on MNIST recognizes:

- MNIST test digits sent by `tools/send_digits.py` over the USB serial
  port: the board shows the digit, its answer, the probabilities and the
  running score
- digits drawn on the board, recognized while they are drawn

## Usage

    make flash
    make BOARD=adafruit-pybadge flash

The default board is `adafruit-clue`. The Python tools need the venv at the
top of the repository, see its README. Then, from this directory:

    ../.venv/bin/python tools/send_digits.py                     # one random digit
    ../.venv/bin/python tools/send_digits.py --count 20 --delay 1
    ../.venv/bin/python tools/send_digits.py --digit 7 --plot    # matplotlib window
    ../.venv/bin/python tools/send_digits.py --count 1000 --quiet
    ../.venv/bin/python tools/send_digits.py --normalize         # shrunk, moved digits
    ../.venv/bin/python tools/send_digits.py listen              # digits drawn on the board

`--port` selects the serial port, `/dev/ttyACM0` by default. MNIST is
downloaded from OpenML on the first run and cached in `~/scikit_learn_data`.

## Controls

    A (held): draw
    B:        clear
    d-pad:    move the pen (PyBadge)
    tilt:     move the pen (CLUE)
    SELECT:   sound on or off (PyBadge)

A drawing is sent to `send_digits.py listen` once the pen has been up for
1.5 seconds.

## How it works

- `digits.c` prepares a drawing the way MNIST digits were prepared: scaled
  to fit a 20x20 box, then moved so that its center of mass is at the
  center of the 28x28 image. MNIST digits sent with `D` are already
  prepared, `--normalize` sends shrunk and moved digits with `N` to
  exercise that step.
- The image is reduced to 14x14 by averaging 2x2 blocks, then classified
  by the network from `model.h`.
- `protocol.h` describes the line protocol.

## Training

`model.h` is generated by `tools/train.py`, with the emlearn version of the
RIOT package (0.21.1):

    ../.venv/bin/python tools/train.py              # 64 hidden neurons
    ../.venv/bin/python tools/train.py --hidden 32  # half the flash

It trains on the MNIST training set and on binarized copies of it, closer
to the strokes drawn on the board: 97.7% of the test digits are recognized,
97.4% of the binarized ones.

## Tests

    make -C tests/host          # digits.c on the host, the 10000 test digits
    make -C tests/host native   # the application built for native64

The C code and scikit-learn agree: 9774 of the 10000 test digits are
recognized on the host, as in Python.
