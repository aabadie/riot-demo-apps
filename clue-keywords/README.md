# Color Words

Keyword spotting taught on the board: teach four words, then saying one paints the screen with its color. Uses the emlearn FFT and mel filterbank, and dynamic time warping.

## Usage

    make RIOTBASE=<RIOT tree with the demo-apps branch> flash term

The default board is `adafruit-clue`.

## Controls

    A: select a word
    B: record the next utterance as an example of it (B again cancels)

See the README at the top of the repository for the details and the board
notes.
