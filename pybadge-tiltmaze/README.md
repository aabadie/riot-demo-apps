# Tilt Maze

Roll a ball through random mazes by tilting the PyBadge.

## Usage

    make RIOTBASE=<RIOT tree with the demo-apps branch> flash term

The default board is `adafruit-pybadge`.

## Controls

    B: set the current position as flat
    START: pause
    SELECT: sound on/off

See the README at the top of the repository for the details and the board
notes.
