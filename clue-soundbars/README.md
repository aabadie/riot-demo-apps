# Sound Bars

Live spectrum, level meter and level history of the CLUE microphone, with lvgl v9 and the emlearn FFT.

## Usage

    make RIOTBASE=<RIOT tree with the demo-apps branch> flash term

The default board is `adafruit-clue`.

## Controls

    A: next view (spectrum, level, history)
    B: microphone gain (0, +10, +20 dB)

See the README at the top of the repository for the details and the board
notes.
